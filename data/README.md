# Dataset Information

This project uses the **DataCo SMART SUPPLY CHAIN FOR BIG DATA ANALYSIS** dataset.

- **Source:** [Kaggle – DataCo SMART SUPPLY CHAIN Dataset](https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis)
- **Usage:** Supply chain analytics, sales and profitability analysis, and delivery performance evaluation.
- **Data Availability:** The dataset is not included in this repository due to its size. Please download it from the original source.
